# Data

본 프로젝트는 VALUE Search에서 수집한 2021~2023년 기업 재무데이터를 사용합니다.

원본 데이터의 재배포 권한을 확인할 수 없어 데이터 파일은 공개 저장소에 포함하지 않습니다.

분석 코드를 실행하려면 다음 파일을 이 디렉터리에 배치해야 합니다.

```text
data/상장폐지_예측데이터셋(2021~2023).csv
```

코드에서 사용하는 주요 열은 다음과 같습니다.

- `업체코드`
- `종목코드`
- `종목명`
- `상장폐지일`
- `상장폐지여부`
- `기업규모`
- 2021~2023년 재무비율 변수

`기업규모`는 대기업, 중견기업, 중소기업 구분을 사용하며 결측치의 그룹별 중앙값 대체에 활용합니다.
