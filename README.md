# Corporate Delisting Risk Prediction

2021~2023년 재무비율과 결측 패턴을 활용하여 2024년 기업의 상장폐지 위험을 예측한 머신러닝 프로젝트입니다.

## 프로젝트 소개

상장폐지 기업은 정상 기업에 비해 표본 수가 매우 적고, 재무 공시 데이터에는 결측치가 빈번하게 존재합니다. 본 프로젝트는 이러한 실제 재무데이터의 특성을 고려하여 **기업 규모별 결측 대체**, **결측 Indicator**, **클래스 불균형 보정**, **F2-score 기반 임계값 탐색**을 결합한 상장폐지 위험 예측 파이프라인을 구축한 프로젝트입니다.

기본 모델은 해석 가능성을 고려하여 Logistic Regression을 사용하였으며, 상장폐지 기업을 놓치는 False Negative를 상대적으로 중요하게 보기 위해 F2-score를 주요 평가 지표로 사용하였습니다.

## 데이터 및 분석 설계

- 분석 데이터: 2021~2023년 기업 재무비율 데이터입니다.
- 예측 대상: 2024년 상장폐지 여부입니다.
- 데이터 출처: VALUE Search입니다.
- 주요 재무비율: 유동비율, 당좌비율, 매출액순이익률, 총자본이익률, 총자본회전율, 매출채권회전율, 재고자산회전율, 고정자산회전율, 매출액증가율, 총자산증가율 등입니다.
- 기업 규모: 대기업, 중견기업, 중소기업으로 구분하여 결측치 대체에 활용하였습니다.
- 데이터 분할: stratified train/test split을 적용하였습니다.

원본 데이터는 재배포 권한을 확인할 수 없어 저장소에 포함하지 않았습니다.

## 분석 파이프라인

1. **식별자 제거 및 수치형 변환**  
   업체코드, 종목코드, 종목명, 상장폐지일 등의 식별 정보를 제거하고 재무 변수를 수치형으로 변환합니다.

2. **Missing Indicator 생성**  
   결측치가 5건 이상 존재하는 변수에 대해 결측 여부 자체를 나타내는 이진 변수를 생성합니다. 총 30개의 Missing Indicator가 생성됩니다.

3. **Train/Test 분할**  
   상장폐지 여부의 클래스 비율을 유지하기 위해 stratified split을 적용합니다.

4. **기업 규모별 중앙값 대체**  
   훈련 데이터에서 대기업·중견기업·중소기업별 중앙값을 계산하여 결측치를 대체합니다. 기업 규모가 없거나 그룹별 중앙값으로 대체되지 않는 값은 훈련 데이터 전체 중앙값을 사용합니다.

5. **다중공선성 통제**  
   원본 수치형 변수에 대해 VIF를 계산하고 VIF가 10 이상인 변수를 제거합니다. Missing Indicator를 포함한 최종 입력 변수는 47개입니다.

6. **표준화**  
   StandardScaler를 훈련 데이터에 적합한 뒤 테스트 데이터에 동일하게 적용합니다.

7. **클래스 불균형 보정**  
   훈련 데이터의 상장폐지 기업이 매우 적기 때문에 RandomOverSampler를 적용합니다. 훈련 데이터 기준 정상기업 2,019건과 상장폐지기업 51건을 각각 2,019건으로 맞춥니다.

8. **Logistic Regression 학습**  
   해석 가능성이 높은 로지스틱 회귀 모델을 학습합니다.

9. **F2-score 기반 Threshold 탐색**  
   0.01부터 0.99까지 분류 임계값을 탐색하여 F2-score가 가장 높은 지점을 확인합니다.

10. **변수 중요도 해석**  
    표준화된 입력 변수의 로지스틱 회귀 계수와 Odds Ratio를 계산하여 주요 변수를 확인합니다.

## 주요 결과

| Metric | Threshold 0.50 | Threshold 0.71 |
| --- | ---: | ---: |
| Accuracy | 0.9305 | 0.9807 |
| Precision | 0.2326 | 0.5882 |
| Recall | 0.7692 | 0.7692 |
| F1-score | 0.3571 | 0.6667 |
| F2-score | 0.5263 | 0.7246 |
| False Positives | 33 | 7 |

기본 임계값 0.50에서 F2-score는 0.5263이었으며, 탐색된 임계값 0.71에서는 0.7246으로 증가하였습니다. Recall은 0.7692로 유지되면서 False Positive는 33건에서 7건으로 감소하였습니다. 기본 모델의 ROC-AUC는 0.9124입니다.

절대 회귀계수 기준으로는 `재고자산회전율1_2023`이 가장 큰 계수를 보였으며, `매출액순이익율_2022_missing`과 같은 결측 Indicator도 상위 변수에 포함되었습니다. 이는 본 프로젝트에서 결측 패턴 자체를 별도의 정보로 활용한 이유를 보여주는 결과입니다.

## 실행 방법

1. 필요한 라이브러리를 설치합니다.

```bash
pip install -r requirements.txt
```

2. 분석용 CSV 파일을 다음 경로에 배치합니다.

```text
data/상장폐지_예측데이터셋(2021~2023).csv
```

3. 저장소 루트에서 분석 코드를 실행합니다.

```bash
python src/delisting_prediction.py
```

## 재현 및 해석 시 참고사항

본 저장소의 코드는 학부 프로젝트 당시 수행한 분석 흐름을 실행 가능한 Python 스크립트로 정리한 것입니다. 원 프로젝트에서는 최적 threshold를 hold-out test set에서 탐색한 뒤 동일 데이터에서 성능을 확인하였습니다. 따라서 위 threshold 기반 수치는 프로젝트 당시의 실험 결과를 재현하기 위한 값이며, 엄밀한 일반화 성능 평가를 위해서는 별도의 validation set 또는 cross-validation을 이용해 threshold를 선택한 뒤 독립 test set에서 최종 평가하는 방식이 적절합니다.
